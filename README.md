# Cat Facts

A small React app that shows random cat facts from the [catfact.ninja](https://catfact.ninja) API.

**Live demo:** https://catfacts-gamma.vercel.app/

## Features

- Get a new random fact
- Save facts to favourites
- History of facts you've already seen
- Favourites and history are kept in localStorage

## Built with

React, TypeScript, Redux Toolkit, React Query, React Router, Tailwind CSS, Vite

React Query handles fetching from the API and Redux holds the favourites and history.

## Run locally

```bash
npm install
npm run dev
```
